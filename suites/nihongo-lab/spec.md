# nihongo-lab E2E 規格

- **目標網站**：`https://nihongo-sync.curio-lab.workers.dev/nihongo-lab/`（同步 Worker 同源提供網頁與 API；舊 GitHub Pages 網址只是遷移引導，不測）
- **來源 Repo**：`frobel0520/nihongo-lab`（網站名稱「かなの日本語」）
- **測試邊界**：只開公開頁面。不點 Google 登入、不觸發跨裝置同步、不下載離線音檔、不播放音檔、不替單字卡評分。每個測試都用 Playwright 新的瀏覽器環境，學習進度只存在測試瀏覽器內，結束即丟棄。

## 核心不變量（依據來源 Repo README 與 docs/release-audit.md）

1. **基線健康**：HTTP 200、非空標題、0 `pageerror`、0 `console.error`、0 同源資源錯誤、桌面（1280×900）與手機（375×812）無橫向捲軸、深淺色主題切換正常。
2. **首頁進課**：首頁標題為「かなの日本語」，提供「開始學習」入口與底部導覽（課程、單字卡、聽寫、跟讀、設定）。點「開始學習」進入 N5 第 1 課（`#/lesson/stage0-day1`），顯示課名與「返回課程清單」連結；底部導覽的聽寫、跟讀、設定頁都能開啟。
3. **單字卡揭示**：未登入也能用單字卡。開 N5 新卡（`#/srs/new?category=n5`）先只顯示詞面與「顯示答案」；按下後顯示讀音與中文意思，並出現「還不會」「記得」兩個評分按鈕。整個過程不送出任何 `POST`／`PUT`／`PATCH`／`DELETE` 請求，也不連到 Google 登入網域。

## 不測範圍

- Google 登入、跨裝置同步、雲端備份。
- 離線音檔下載、真正離線重載、PWA 安裝（會下載大量媒體，不符合禮貌頻率）。
- 教材內容正確性、配音品質、正式效能門檻（由來源 repo 自己的發布稽核負責）。
